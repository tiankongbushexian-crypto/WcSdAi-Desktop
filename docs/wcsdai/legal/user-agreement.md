## Installation and use

WcSdAi is based on the open-source PI-Desktop project. The original LGPL terms
and each component's license govern installation, copying, modification and
distribution of covered code. Read `NOTICE.md`,
`LICENSE` and `THIRD_PARTY_NOTICES.md`.
This agreement does not add restrictions that conflict with those rights.

The desktop can read and change authorized project files, execute approved
commands and connect to selected providers and extensions. Users choose their
project roots and provider accounts and remain able to review permissions.
The brand change preserves agent, plugin, MCP and session contracts and does
not automatically enable dangerous commands.

## Accounts, data and external services

Keep credentials private and use only authorized accounts. Model providers and
extension publishers may apply their own prices, licenses and privacy terms.
Review these before use; WcSdAi does not guarantee third-party availability,
output accuracy or cost limits unless separately agreed in final terms.

The [privacy-policy draft](privacy-policy.md) describes the data-flow review
required before publication. Back up important sessions and projects before
upgrades or removal. Old data compatibility must be validated with isolated
fixtures for each release; it is not an instruction to delete existing data.
