## Data used by the desktop application

WcSdAi provides a desktop workspace for projects, sessions and AI agents. Its
host components maintain local project references, conversations, session state,
preferences and operational records. Provider configuration and authentication
material are handled by the existing host/runtime mechanisms. The brand change
preserves existing storage paths and formats; this statement does not promise
that every local data file is encrypted.

Data may include prompts, conversation history, file contents and attachments
the user supplies or permits tools to access, model/provider selections,
generated outputs, command results, approval decisions, plugin settings and
diagnostic information. A project may contain personal or confidential data;
review what a selected model, tool or extension receives before authorizing it.

## Connections outside the device

When a user invokes a configured model/provider, relevant request content and
authentication information are transmitted to that configured service. OAuth
sign-in uses the selected vendor's account flow. The provider's own processing,
retention, billing and policy terms apply independently.

Enabled plugins, MCP servers, Skills, browser tools, remote hosts and optional
sync features can access or transmit data within their granted capabilities.
Catalog browsing, update checks and downloads can contact their configured
marketplace/release hosts and disclose ordinary connection metadata, including
IP address. Plugin and model services are not all operated by 量动科技.

This brand migration preserves existing telemetry behavior and adds no new
collector. The installed Pi telemetry package provides no-op and in-memory
contexts; this observation alone does not establish all network behavior of
providers or extensions. Before publication, complete a release-build audit of
exporters, diagnostics, crash collection, identifiers, destinations, retention
and user controls. Do not publish a claim of "no telemetry" without that audit.

## User controls and retention

Users choose providers and projects, review permissions, manage sessions and
extensions, and can avoid connecting optional services. Deleting local data does
not itself delete data already retained by an external service or a backup.
Before uninstalling or removing state, export or back up information you need.

The operator must document supported deletion/export procedures, diagnostic
retention periods, backup handling, third-party retention links and a response
process for privacy requests before release. No fixed retention or guaranteed
deletion deadline is asserted in this draft.

## Publication requirements

Confirm applicable legal grounds and notices, age/minor handling, international
data flows, processors, security contact procedures and policy change notices
for each market where the app will be distributed. This draft does not create
an account-registration service or promise a specific hosting location.

Any material future change in collection or purpose must be reflected in the
published policy and corresponding product controls before it takes effect.
