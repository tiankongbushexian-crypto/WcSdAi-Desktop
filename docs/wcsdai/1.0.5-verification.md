# WcSdAi 1.0.5 verification

## Scope and compatibility

The owner reported three defects in 1.0.4: the AI service editor collapsed its
configured-model list on a short macOS window; Windows window corners and edges
were difficult to distinguish from a light desktop background; and the default
assistant still introduced itself as PI-Desktop.

This request fixes those surfaces and prepares unsigned team installers for
macOS arm64/x64 and Windows x64. The owner authorized normal PR integration,
GitHub installer publication and a local macOS upgrade. Local replacement must
follow a verified stopped-app backup. Existing projects, sessions, provider
credentials, permissions, profile directories and compatibility aliases remain
unchanged. Tests use disposable state and local model fixtures; no real model
provider is needed.

The product identity is WcSdAi. Actual provider/model identifiers remain intact;
WcSdAi is not presented as the underlying model. Existing custom `SYSTEM.md`
precedence and historical conversation content are retained. Technical package
names, IPC identifiers, the encryption namespace and upstream attribution are
not subject to global string replacement.

## Regression evidence

- The reported 1188×794 provider dialog exposed only a 38px configured-model
  viewport before the fix. Its real Chromium regression failed. The stacked
  grid now retains 238px at that size and 168px at 800×560. Six service/account,
  English/Chinese and zoom scenarios completed the last-model edit, search,
  save and reopen path with actual production components/CSS. Only the external
  API boundary is a fixture; no Host persistence claim is made by this test.
- Five actual runtime/Pi-adapter/localhost HTTP tests failed on the old default
  identity and passed after correction. They cover Agent/Plan/Goal, restored
  history, mode switches and custom persona precedence. Runtime regression
  tests passed 1,160 cases; Live Work service/bridge checks passed 10 cases.
- The Windows default-radius regression failed at 4 versus 12 DIP, and the
  isolated renderer probe failed for the missing perimeter before the fix.
  Independent review also identified zoom alignment and initial fullscreen
  state. The fixed production renderer passed actual Electron page zoom
  0.5/1/1.5/3 with a 12 DIP radius and approximately 1 DIP border, including
  initial fullscreen snapshot recovery, stale replies and lifecycle cleanup.
  The 34 related window tests passed. Windows native region checks are wired
  into the Windows installer job and remain pending until that runner executes.
