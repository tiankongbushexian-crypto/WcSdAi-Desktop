  result path now reveals the matched file in Finder/Explorer. Office and HTML
  outputs do not depend on document preview support. Explicit image preview
  controls and HTTP browser preferences remain available.

  Markdown cleanup pipeline. Explicit filenames with spaces, Chinese text,

  lists retain entries belonging to the originating session's workcopy/scratch.

  deleted session or missing independent workcopy does not fall back to the
  currently selected project. Canonical/symlink containment is unchanged.
- Windows interface-format menus use the existing viewport overlay root, above
  the masked window body and modal backdrop. Selecting a format, editing models,
  saving and reopening works in the tested configurations. Website-managed
  model protocols still follow website authorization; BYOK remains configurable.
- Recharge, Refresh and Sign out stay on one aligned line. Narrow cards move
  the complete group beneath the description. Labels use existing translations;
  the recharge button keeps its full accessible action name.

No account, billing, API provider, personal parameter, session format or database
migration was introduced. No production profile was opened or modified. The API
website backend is not redeployed for this client-only release.

## Limits

The file fixture captures the final OS shell handoff; it does not claim physical
Finder/Explorer inspection. Files must exist inside the existing allowed roots;
stored tool text is not authorization to reveal arbitrary external paths, and
remote sandbox names are not guessed from local basenames. Explicit previews
remain separate actions. CSS Windows simulation is not native Windows evidence.
Native CI does not cover every physical display, GPU or scaling configuration.

No real OAuth, paid model, recharge or installed-profile interaction was used.
The user's installed application is not replaced. These remain unsigned team
builds with the existing ad-hoc macOS integrity seals. Existing dependency
advisories are not represented as resolved by this UI-focused maintenance.
