  fixing Grok's protocol mismatch. Personal tuning cannot redirect a scoped
  grant. Manually configured API providers retain their existing behavior.

  and personal parameters intact. Actual entitlement restrictions remain
  enforced. The client does not silently choose another billing group.

  Current selections, full-ID search, custom names and independently tuned
  aliases remain available.

  desktop device. Filtering and exports agree; restricted user and observer
  responses remain scoped.

Existing local accounts, API providers, model preferences and sessions require
no reset. Billing calculations are unchanged. Updates remain manually installed.
