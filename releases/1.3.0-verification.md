## Limits and compatibility

Account model preferences are local and cannot expand website permissions. Image
support requires the deployed v2 website contract and a supported upstream image
protocol. Synthetic paid HTTP edges prove routing/retry behavior, not real provider
output quality or payment fulfillment. Token expiry, revocation and safeStorage
remain enforced. Original API providers and sessions are preserved. Schema 24 adds the workcopy registry with an upgrade backup; older applications cannot directly open the new database.

Actual Windows desktop evidence used `Windows Server 2025 Datacenter` / release
`10.0.26100` at DPI 96. The separate
Chromium matrix emulates display scales 1, 1.25 and 1.5 at zoom factors 0.8, 1 and
1.5; it does not claim that multiple physical Windows monitors or native DPI
settings were tested. More native display-scale testing remains useful.

The planned validation fixtures use isolated synthetic profiles. A separate local
executable-inspection mistake started a candidate Host against the operator's
existing profile, applying the additive schema migration and plugin reconciliation.
Publication was paused and the incident was disclosed. After explicit recovery
authorization, the original application restored its plugin registrations and
exited normally. Recovery first backed up the current state, then removed only
the new empty table and schema-version marker. Independent comparison preserved
all 30 original tables, current rows and rowids; integrity checks passed and the
original 1.2.0 application reopened. No older backup replaced current user rows.
Private recovery evidence is not included in this public report.
Publication and local installation are separate operations; the installed
application was not upgraded by this release publication.
No real payment or paid model request was made by these maintenance tests.
Account status and allowed models continue to depend on the website's actual
permissions and credited balance. Existing API providers, sessions and permissions
remain supported; the application still performs manual update installation.

These team builds have no Apple Developer ID/notarization or Windows publisher
certificate. CI validates macOS bundle integrity before artifact collection.
The 1.1.1 Electron/network security baseline remains, but this change is not an
all-clear dependency audit. Preserve and consult the
[historical 1.1.1 assessment](1.1.1-verification.md) and
[dependency snapshot](1.1.1-dependencies.json).
